Open data and code
------

* **Speech adaptation and tDCS.** Preregistration, data and analysis code for the brain stimulation study published in *Cortex* (2025): [osf.io/9bswe](https://osf.io/9bswe/).
* **Speech tracking in bilinguals.** Preregistration for the EEG study of continuous speech tracking in noise, published in [*Brain and Language* (2022)](https://doi.org/10.1016/j.bandl.2022.105128): [osf.io/xyqfr](https://osf.io/xyqfr/).
* **Chinese characters and words database.** A database of ~3,000 characters and ~2,200 words from primary-school textbooks, described in [*Behavior Research Methods* (2024)](https://doi.org/10.3758/s13428-023-02214-1).

Methods and tools
------

* **Neuroimaging analysis:** task and resting-state fMRI, structural MRI, multivoxel pattern analysis (MVPA), effective-connectivity network modelling (euSEM, dynamic causal modelling), EEG (continuous neural tracking, ERPs)
* **Software and programming:** MATLAB, Python, R, FSL, SPM
* **Pipelines:** reusable, version-controlled analysis pipelines for MRI data
* **Open science:** preregistration, code and data sharing
